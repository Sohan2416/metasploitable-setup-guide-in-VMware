# Metasploitable 2 & Kali Linux Setup & Networking Troubleshooting Guide

This repository contains a comprehensive step-by-step documentation (PDF) for installing **Metasploitable 2** on VMware/VirtualBox, along with real-world troubleshooting solutions for **Kali Linux network configuration errors**.

---

What's Included in the PDF?

 1. Metasploitable 2 Setup & Installation
- Complete hardware allocation (Processor, RAM, Network Type).
- Attaching existing VMDK virtual disk files correctly.
- Initial boot process and default login credentials (`msfadmin:msfadmin`).

 2. Kali Linux Network Error Fixes
- Fixing "Network autoconfiguration failed" (DHCP issues).
- Resolving Ethernet Network disconnected state in Kali Linux.
- Fixing `NetworkManager.service not found` or syntax errors (`NetworkManager~`).
- Configuring `/etc/NetworkManager/NetworkManager.conf` (`managed=true`).
- VMware / VirtualBox Network Adapter & Virtual Network Editor reset guides.

---

How to Access
Download the `Metasploitable_Kali_Setup_Guide.pdf` file directly from this repository or view it online via GitHub's PDF viewer.

---

System Requirements
- Hypervisor: VMware Workstation / VirtualBox
- OS Images: Metasploitable 2 VMDK, Kali Linux ISO
